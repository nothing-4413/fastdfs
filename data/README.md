# data

This directory stores runtime data generated by tracker and storage.

## Main Runtime Files

| Path | Purpose |
|---|---|
| `tracker/file_index.dat` | Persistent file location index |
| `storage1/binlog.dat` | Storage1 operation log |
| `storage2/binlog.dat` | Storage2 operation log |
| `storage*/files/` | Real uploaded files |
| `*.meta` | File metadata |

## Git Notes

Runtime data should normally not be committed.

A recommended `.gitignore` rule:

```gitignore
data/tracker/file_index.dat
data/storage*/binlog.dat
data/storage*/files/*
