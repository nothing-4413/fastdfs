# docs

This directory stores project design documents.

## Suggested Documents

| Document | Purpose |
|---|---|
| `architecture.md` | Overall architecture |
| `protocol.md` | Protocol design |
| `upload-flow.md` | Upload workflow |
| `download-flow.md` | Download workflow |

## Purpose

The docs directory is used to record design decisions and explain how major workflows are implemented.

It should focus on architecture and workflow, not on repeating source code.
